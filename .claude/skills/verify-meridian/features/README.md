# MERIDIAN 공개 사이트 기능 지도

공개 사이트를 검증하는 기준 문서다. 구동하기 전에 이 목록을 읽고, 맞는 기능 파일을 따라 구동한다.

## 기본 전제

- `npm run build` 뒤 `verify.mjs start` 로 띄운 :3100. `verify.mjs doctor` 가 정상이어야 한다.
- `CONTENT_DB` 없이 빌드했으면 블로그 글은 0개, 일정과 FAQ 는 코드 배열이다.
- 이 도구가 띄우지 않은 서버는 구동하지 않는다.

## 구동 규칙

- 접근 가능한 이름(`getByRole`, `getByLabel`)을 먼저 쓴다. CSS 선택자는 이름이 없는 곳에만.
- 데스크톱 1440x900 과 모바일 390 너비 둘 다 본다. 모바일 메뉴는 다른 진입점이다.
- 증거는 `artifacts/verify/<label>/<기능>/` 에 남긴다. 행동 전후 화면과 응답, 콘솔 오류를 같이.
- 갈 수 없는 경로는 시도한 명령과 채워지지 않은 전제를 적고 실패로 보고한다. 통과시키려고 여정을 줄이지 않는다.

## 기능

| 기능 | 파일 | 도구 명령 |
|---|---|---|
| 문의 보내기 | `contact.md` | `verify.mjs contact <label>` |
| 사이트 검색 | `site-search.md` | `verify.mjs search <label>` |
| 세무 일정 | `tax-calendar.md` | `verify.mjs schedule <label>` |
| 블로그 목록과 글 | `blog.md` | 아직 구동해 보지 않았다(글이 있는 DB 필요) |
