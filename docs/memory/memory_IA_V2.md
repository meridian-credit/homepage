## 무슨 이야기냐

사이트 구조가 꼬였다. 그걸 어떻게 풀지 정한 문서다.

## 제일 큰 문제 하나

**「서비스」를 눌러도 서비스가 안 나온다.**

- `/services` 는 7,730px 인데 제목이 3개뿐
- 가운데를 「붙잡는 스크롤」이 차지해서 6개를 하나씩 넘겨야 봄
- 진짜 설명은 그 아래 상세 6장에 따로 있음
- **같은 6개를 세 번 다룬다** — 홈 카드 → 붙잡는 스크롤 → 상세

## 나머지 문제

| 문제 | 숫자 |
|---|---|
| 최종 페이지가 3단 아래 | 메뉴 → services → 상세 |
| 막다른 페이지 | portal(19,682px에 링크 1) · pricing(1) · members(0) |
| portal 이 홈보다 김 | 19,682 vs 12,053 |
| 홈이 다 떠안음 | 제목 22개 |
| 페이지마다 이동 장치가 다름 | 앵커 / 붙잡는 스크롤 / 위저드 |
| 일부러 가린 페이지 | `/pricing` `/preview` |

## 지킬 것 4개

1. 두 번 안에 닿는다
2. 한 페이지는 한 가지 일만
3. 같은 내용은 한 군데가 원본
4. 페이지 안 이동 장치는 하나만

## 새 메뉴

`메리디안 · 서비스 · 대시보드 · 고객사 · 인사이트 · (수임료)` + 기장 문의하기

**서비스 드롭다운이 상세 6장으로 바로 간다.** 중간 페이지를 건너뛰어서 3단이 2단이 된다.

## 할 일 순서

| | 뭘 | 얼마나 |

| 1 | 드롭다운 → 상세 직행 | 이미 됨 |

## 안 건드리는 것

**주소는 하나도 안 바꾼다.** 검색 순위가 끊긴다.

## `/pricing` — 정했다

- 메뉴·사이트맵·검색에서 빼고, 페이지는 noindex 로 둔다.
- robots 로는 막지 않는다. 막으면 검색엔진이 noindex 를 못 읽는다.
- 공개 여부는 따로 정한다.
